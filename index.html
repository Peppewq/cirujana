Cirujana

A personal surgery log for Android

Cirujana is an Android app for surgeons to keep a private log of the surgeries they perform: date, case number, procedure type, status and notes.

Features

  • Add surgeries with a step-by-step form
  • Sortable table of all surgeries
  • Edit history with restore of any previous version
  • Trash with 30-day recovery
  • Statistics per procedure type
  • Interface in Spanish and Italian
  • Optional backup of the database and a CSV export to the user's own Google Drive

Your data

Cirujana has no server and no account. All data stays on the phone. The only data that leaves the phone is the optional backup, which is written to the user's own Google Drive. Read the privacy policy for details.
